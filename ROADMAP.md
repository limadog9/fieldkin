# Modest roadmap

- Validate the current scoring/abstention defaults against more labeled,
  redistribution-compatible schema pairs and document domain-specific tradeoffs.
- Improve prepared sample/name reuse if the recorded benchmarks justify API cost.
- Review data-type granularity and ambiguity diagnostics with real callers.
- Stabilize the public API after downstream use, then consider a first crates.io
  publication under the sole maintainer's control.

No committed schedule. Nested transformations, rewriting data, embeddings,
Python bindings, dataframe adapters, hosted services and plugin frameworks are
outside the current release scope.
