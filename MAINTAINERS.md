# Maintenance

**Sole maintainer and final decision-maker: [@limadog9](https://github.com/limadog9).**

There are no other appointed maintainers, write collaborators, or publishing
owners. Releases, API direction, dependency choices and contribution acceptance
are decided by @limadog9. Response times are best effort; no support SLA is offered.

The implementation is maintained on main. This is not a crates.io release.
Outside contributions require @limadog9's code-owner approval. At the owner's
explicit request, administrators are exempt from the PR/review requirements so
the owner can merge their own work. @limadog9 is the only administrator; no other
account has been granted this exception. Adding another administrator would
extend the exception and requires the owner's explicit authorization.

Repository protection is a GitHub configuration, not something this policy file
can enforce. The owner can edit repository settings; no GitHub rule can prevent
an account owner from using their administrative configuration authority.
Authentication as the owner cannot distinguish agent actions from the human
owner. Agent work follows the owner's instructions and must not change access or
protections beyond the authorized scope.
