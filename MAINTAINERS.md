# Maintenance

**Sole maintainer and final decision-maker: [@limadog9](https://github.com/limadog9).**

There are no other appointed maintainers, write collaborators, or publishing
owners. Releases, API direction, dependency choices and contribution acceptance
are decided by @limadog9. Response times are best effort; no support SLA is offered.

The initial implementation is reviewed in a draft PR. This is not a crates.io
release, and main contains only the minimal CI/ownership bootstrap until an
eligible code-owner review can be obtained. Authentication as the owner cannot
distinguish agent actions from the human owner. A separate contributor identity
is necessary for GitHub-enforced personal review of owner-authored work.

Repository protection is a GitHub configuration, not something this policy file
can enforce. The owner can edit repository settings; no GitHub rule can prevent
an account owner from using their administrative configuration authority. Agent
work must not weaken protection or add bypass actors.
